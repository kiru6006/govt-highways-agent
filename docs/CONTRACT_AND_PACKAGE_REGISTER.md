## 6. Raw Source Text Corruption Analysis for Package EPC01

> [!CAUTION]
> **Data Quality Forensic Notice on Package EPC01**:
> - In several source printouts and tabular PDF extracts, the row for **EPC01** suffered character transposition:
>   - Length was printed with an asterisk (`48.482*`), combining SH-116 (22.4 km) and SH-58 (26.082 km).
>   - The cost column had an incomplete entry in raw tables (`184.98` vs aggregate multi-component lines).
> - **Reconciliation**:
>   - Total package length = $22.400 \text{ km} + 26.082 \text{ km} = 48.482 \text{ km}$.
>   - Total package agreement value = **₹184.98 Crore**.
>   - When summed with EPC02 through EPC10, the total rigorously equals:
>     $$\sum_{i=1}^{10} \text{Cost}_i = \text{₹1,704.91 Crore}$$
>     $$\sum_{i=1}^{10} \text{Length}_i = 427.967 \text{ Km}$$
